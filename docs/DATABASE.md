# StudyFlow — Database Schema Reference

Mirrors Chapter Three, Section 3.6.2 of the project report. This is the reference used when writing the actual Supabase SQL migrations later, do not let this drift from the report.

## Tables

### `users`
| Field         | Type       | Constraint      | Description                                   |
|---------------|------------|------------------|-------------------------------------------------|
| id             | UUID       | PK               | Auto-generated by Supabase Auth                 |
| email          | VARCHAR    | UNIQUE NOT NULL  | Login email                                      |
| full_name      | VARCHAR    | NOT NULL         | Student's full name                              |
| matric_no      | VARCHAR    | UNIQUE           | NOUN matric number (optional)                    |
| created_at     | TIMESTAMP  | DEFAULT NOW()    | Record creation timestamp                        |

### `courses`
| Field         | Type       | Constraint          | Description                                          |
|---------------|------------|----------------------|--------------------------------------------------------|
| id             | UUID       | PK                   | Unique course record ID                                |
| user_id        | UUID       | FK → users           | Owning student                                          |
| course_name    | VARCHAR    | NOT NULL             | Full course name (e.g. "Data Structures")               |
| course_code    | VARCHAR    |                       | e.g. "CIT 321"                                           |
| credit_hours   | INTEGER    | NOT NULL             | Used as weighting input to the scheduling algorithm      |
| material_url   | TEXT       | NULLABLE             | Supabase Storage URL of uploaded PDF                     |
| created_at     | TIMESTAMP  | DEFAULT NOW()        |                                                            |

### `availability`
| Field         | Type       | Constraint      | Description                                       |
|---------------|------------|------------------|------------------------------------------------------|
| id             | UUID       | PK               |                                                        |
| user_id        | UUID       | FK → users       |                                                        |
| day_of_week    | VARCHAR    | NOT NULL         | Monday … Sunday                                        |
| start_time     | TIME       | NOT NULL         | Start of available study window                        |
| end_time       | TIME       | NOT NULL         | End of available study window                          |
| created_at     | TIMESTAMP  | DEFAULT NOW()    |                                                          |

### `timetable_entries`
| Field         | Type       | Constraint            | Description                                     |
|---------------|------------|-------------------------|----------------------------------------------------|
| id             | UUID       | PK                      |                                                      |
| user_id        | UUID       | FK → users              |                                                      |
| course_id      | UUID       | FK → courses            |                                                      |
| day_of_week    | VARCHAR    | NOT NULL                | Day this session is scheduled                       |
| start_time     | TIME       | NOT NULL                |                                                        |
| end_time       | TIME       | NOT NULL                |                                                        |
| is_completed   | BOOLEAN    | DEFAULT FALSE           | Student marks session complete                       |
| created_at     | TIMESTAMP  | DEFAULT NOW()           |                                                        |

### `notifications`
| Field                | Type       | Constraint                    | Description                                  |
|-----------------------|------------|----------------------------------|-------------------------------------------------|
| id                     | UUID       | PK                               |                                                   |
| user_id                | UUID       | FK → users                       |                                                   |
| timetable_entry_id     | UUID       | FK → timetable_entries           |                                                   |
| scheduled_at           | TIMESTAMP  | NOT NULL                         | When the push notification should fire           |
| is_sent                | BOOLEAN    | DEFAULT FALSE                    |                                                    |
| created_at             | TIMESTAMP  | DEFAULT NOW()                    |                                                    |

## Row Level Security

Every table (except `users`, which is keyed to `auth.uid()` directly) enforces:

```sql
-- Example RLS policy pattern applied to each table
create policy "Users can only access their own rows"
on <table_name>
for all
using (auth.uid() = user_id);
```

## Migration order

When Supabase is set up, run migrations in this order:
1. `users` (or rely on Supabase's built-in `auth.users` + a `profiles` trigger)
2. `courses`
3. `availability`
4. `timetable_entries`
5. `notifications`
6. RLS policies for all tables
7. Storage bucket for course materials (private, per-user folder convention: `materials/{user_id}/{course_id}.pdf`)
